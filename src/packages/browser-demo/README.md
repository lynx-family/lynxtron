# Browser demo moved

The complete browser app and its template generator are maintained with Lynxtron
Go in [lynxtron-examples/showcases/browser](https://github.com/lynx-community/lynxtron-examples/tree/main/showcases/browser).

Use Go's Browser showcase, or follow that directory's README to build the source
and a standalone installer. The Lynxtron runtime repository no longer keeps a
second browser implementation or publishes its template generator.
